# AIRWAY QUEST｜3D 高擬真化計畫（medical-grade realistic simulation）

## 結論先說

先前的 3D 病人與器械是用 sphere、cylinder、box 等基本幾何體拼成的，所以看起來像黏土公仔。這種做法無法透過調參數變成「醫學模擬教學軟體」等級。

要達到要求的擬真度，必須有專業製作的 3D 資產：

- 經掃描或建模的訓練模型與器械
- 完整的 PBR 貼圖

目前專案、程式碼與這次的開發環境都沒有這些資產：

- 可下載免費 HDRI 與貼圖的 Poly Haven 在此環境被封鎖
- 也找不到授權清楚、外觀擬真的成人氣道訓練模型或臨床器械模型

因此這一版刻意不再假裝已完成高擬真 3D，而是做三件事：

1. **移除黏土模型**：3D 場景不再以基本幾何體拼湊病人與器械。
2. **建好資產管線**：GLB 載入、PBR 渲染、接觸陰影、柔光環境光、案例規則驅動的 morph 與掛載點都已就緒。資產放到 `public/models/airway/` 就會自動啟用。
3. **誠實的備援畫面**：必要資產缺少時，3D 視角自動改用 2D 教學示意圖，並標示「3D 資產待補」。介紹頁、練習、示範三處皆同。

## 1. 現有問題分析

| 問題 | 原因 |
| --- | --- |
| 黏土、玩具感 | 病人由十幾個縮放球體與圓柱組成，沒有真實的拓樸與表面細節 |
| 比例失真 | 頭、頸、胸是獨立的幾何體，沒有骨架或解剖參考，只靠目測擺位 |
| 材質單薄 | 只有單一顏色加 roughness，沒有 normal、AO、細部貼圖，也沒有次表面散射的色彩變化 |
| 光影平 | 只有半球光加一盞平行光，沒有環境反射與接觸陰影，也沒有色調映射 |
| 器械失真 | 喉頭鏡、氣管內管、袋瓣罩只是圓柱、方塊與環，比例與結構都不對 |
| 場景抽象 | 只有地板、桌子與方塊，不是臨床技能中心或 OSCE 考站的樣子 |

### 建議取得方式（依推薦順序）

1. **掃描中心自己的訓練模型（最推薦）**
   - 用 RealityScan、Polycam 等攝影測量 App 掃描臨床技能中心現有的氣道訓練模型與器械。
   - 交給 3D 美術在 Blender 整理：重拓樸、烘焙 normal 與 AO、拆出可動部位、移除品牌標誌。
   - 外觀與學生實際使用的模型一致，授權問題也最少。
2. **購買商用模型**：例如 CGTrader、TurboSquid 上的 airway trainer、laryngoscope、endotracheal tube、bag-valve-mask、hospital exam room。購買前確認授權允許公開網頁展示。
3. **委託 3D 美術製作**：依上表規格與 `public/models/airway/README.md` 交付。

## 3. 技術改善步驟

| 步驟 | 內容 | 狀態 |
| --- | --- | --- |
| 1 | 資產清單與偵測：`scene/assets.ts` 以 HEAD 請求檢查檔案，必要資產齊全才啟用 3D | ✅ 已完成 |
| 2 | 渲染設定 | ✅ 已完成 |
| 3 | 案例規則驅動 | ✅ 已完成 |
| 4 | 備援：缺資產時 3D 視角改為 2D 教學示意圖並顯示「3D 資產待補」 | ✅ 已完成 |
| 5 | 取得或製作 P0 資產（訓練模型、場景） | ⏳ 需資產 |
| 6 | 壓縮與最佳化（gltf-transform：KTX2、Meshopt、resize），手機以低一級 LOD | ⏳ 需資產 |
| 7 | 後製：SSAO（N8AO）、輕微景深；手機關閉 | ⏳ 資產到位後調整 |
| 8 | 校正：依實體模型照片校正比例、材質色與 roughness；由臨床教師確認器械比例與外觀 | ⏳ |
| 9 | 互動對位：喉頭鏡與氣管內管沿模型口咽的動畫路徑（以示意為主，不宣稱物理精度） | ⏳ |

步驟 2 的渲染設定包含：

- ACES Filmic 色調映射、sRGB 輸出
- PCF soft shadows
- 以 Lightformer 模擬臨床平板燈與窗光的環境反射
- 接觸陰影
- 保留 GLB 原有的 PBR 材質

步驟 3 的案例規則驅動包含：

- 頭部後仰：`Head` 節點
- 雙肺與胃袋鼓起：morph target
- 器械掛載：`Mouth_Socket`，依操作狀態顯示

## 4. 哪些可以用 placeholder，哪些不可以

| 部分 | 可否 placeholder | 說明 |
| --- | --- | --- |
| 病人／訓練模型主體 | ❌ 不可 | 不以幾何體拼湊；缺少時改用 2D 示意圖並明確標示 |
| 呼吸道器械（喉頭鏡、氣管內管、袋瓣罩） | ❌ 3D 中不可 | 缺少時不顯示。器材準備、選擇與操作改由 2D 圖示與互動元件呈現（已完成） |
| 次要耗材（空針、咬口器、固定帶、聽診器） | ⚠️ 3D 中不顯示 | 由 2D 器材盤處理 |
| 場景建築（地板、牆面、天花） | ✅ 可暫用平面與方塊 | 前提是使用 PBR 貼圖。建築本來就由平面構成；病人與器械則不行 |
| 監視器螢幕內容 | ✅ 可程式繪製 | 波形依案例規則產生 |
| 2D 教學示意圖 | ✅ 正式內容 | 標示為原創教學示意圖、非真實解剖影像，可作為長期的比較與解說工具 |

## 5. 驗收清單（資產到位後）

- [ ] 遠看與近看（呼吸道視角）都沒有塑膠、黏土或玩具感；皮膚與矽膠有紋理與光澤差異。
- [ ] 頭頸、肩胸比例符合真實成人訓練模型；臉部五官清楚。
- [ ] 喉頭鏡、氣管內管、袋瓣罩的尺寸與結構正確，由臨床教師確認。
- [ ] 有接觸陰影與空間層次；手機上可流暢操作（≥ 30 fps）。
- [ ] 無未授權的品牌標誌。

## 6. 其他關卡

傷口縫合與導尿管置入的 3D 場景，同樣是以基本幾何體呈現的概念原型，適用相同的資產管線與規格。建議在氣道模型完成驗收後，依同樣流程補齊這兩個關卡的資產：

- 傷口縫合：手部模型、縫合訓練墊、器械
- 導尿管置入：男性導尿模型、導尿包、病床
